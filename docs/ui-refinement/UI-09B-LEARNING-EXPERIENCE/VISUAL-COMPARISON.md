# Visual comparison with the Canva reference

The reference shows upright, rounded, heavy lettering with a cream face and a strong blue perimeter. The implementation keeps those defining cues using custom paths, cream fill, rounded blue joins, and a small blue shadow.

Review the rendered headings on [white](screenshots/heading-on-white.png) and [pastel blue](screenshots/heading-on-pastel-blue.png), and in the [desktop lesson](screenshots/lesson-workspace-desktop-sidebar-expanded-1440x900.png) and [mobile course](screenshots/course-overview-mobile-390x844.png) screenshots.

The shapes are original interpretations based on the single “Canva” wordmark reference, not a reconstruction of a full typeface. At small screen sizes the visible treatment is more outline-forward because the cream face sits on a very pale page surface. The rounded proportions, upright stance, cream fill, and blue outline align with the sample; the exact letter contours and full alphabet do not. No pixel-perfect claim is made.
