# Visual comparison

The old renderer used narrow hand-drawn sans glyphs and a blue stroke around a largely empty fill. The new renderer uses Coiny's heavier rounded forms, an expanded cream body, a separate blue contour, and the same colors as the existing learning UI. Its glyph geometry is generated rather than traced from the customer sample.

The Canva wordmark image supplied in the request was viewed only as a style reference and is not copied into this repository. The comparison is qualitative; the phrase length and letterforms differ, so this is not a pixel-difference or “100% match” claim.
