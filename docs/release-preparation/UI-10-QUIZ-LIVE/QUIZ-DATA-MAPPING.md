The practice lesson is attached to the existing published A1.1 `Lektion 1` section, uses lesson type `PRACTICE`, and has `countsTowardProgress=false`. No course, section, enrollment, price, access-duration, or existing progress records are rewritten.

Each source row maps its question text, A/B/C option text, and answer label to one `SINGLE_CHOICE` question with three ordered options. `A`, `B`, or `C` sets exactly one `isCorrect=true`; whitespace is collapsed and trimmed. Other source content is preserved. Quiz defaults are `passScorePercent=null` and `showCorrectAnswers=true`.

Workbook row and answer keys are not included in student API responses before submission.
