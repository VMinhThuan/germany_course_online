## Contract and business-rule findings

- Automatic 5% discount begins with the second `PAID` `PURCHASE`; pending, cancelled, failed, and renewal orders do not qualify. Backend logic counts prior paid purchases, and the BE-03C policy note reflects that rule.
- Coupon and automatic discounts are compared against the same base amount; only the larger wins. A tie selects the automatic discount, avoiding a coupon reservation with no incremental savings.
- A student transfer report does not mark an order paid or prove funds arrived. Admin approval follows external reconciliation.
- Renewal updates the existing enrollment. A revoked enrollment is not directly renewable; Admin restoration is a separate audited action.
- Quiz submission completes the exercise regardless of score; the attempt preserves its submitted question/answer snapshot after Quiz edits.
- No deployment, production database query/write, production SMTP, or provider upload was performed.
