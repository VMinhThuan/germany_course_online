# Frontend Route Inventory

Production route source: `frontend/src/app/public-site/routes.tsx` and `frontend/src/app/auth/routes.tsx`. `frontend/src/main.tsx` loads `ProductionApp` outside Vite development mode. Admin is lazy-loaded behind the Admin role guard.

| Route                                                                                  | Screen                                 | Access                         | API-backed status                                                            |
| -------------------------------------------------------------------------------------- | -------------------------------------- | ------------------------------ | ---------------------------------------------------------------------------- |
| `/`                                                                                    | Public landing page                    | Guest                          | Integrated: site settings and published courses                              |
| `/courses`                                                                             | Course catalog                         | Guest                          | Integrated: published catalog                                                |
| `/courses/:slug`                                                                       | Course details/outline                 | Guest                          | Integrated: published course detail; private lesson material is not included |
| `/help`                                                                                | Public help                            | Guest                          | Static informational content; no current API operation is needed             |
| `/login`                                                                               | Login                                  | Guest                          | Integrated; role redirect and `returnTo`                                     |
| `/register`                                                                            | Registration                           | Guest                          | Integrated; success does not create a session                                |
| `/forgot-password`                                                                     | Request reset                          | Guest                          | Integrated; delivery depends on backend email provider                       |
| `/reset-password`                                                                      | Reset from email token                 | Guest                          | Integrated; token is supplied by the backend email flow                      |
| `/student`                                                                             | Dashboard                              | Student                        | Integrated: dashboard endpoint                                               |
| `/student/courses`                                                                     | My courses                             | Student                        | Integrated: enrollments and course progress                                  |
| `/student/progress`                                                                    | Progress                               | Student                        | Integrated: server progress                                                  |
| `/student/orders`                                                                      | Order list                             | Student                        | Integrated                                                                   |
| `/student/orders/:id`                                                                  | Order detail                           | Student, owner enforced by API | Integrated                                                                   |
| `/student/courses/:courseId/renew`                                                     | Renewal quote/plans                    | Student                        | Integrated; production renewal journey not browser-E2E tested                |
| `/student/profile`                                                                     | Profile                                | Student                        | Integrated                                                                   |
| `/student/security/password`                                                           | Change password                        | Student                        | Integrated                                                                   |
| `/student/security/sessions`                                                           | Session list/revoke                    | Student                        | Integrated                                                                   |
| `/learn/courses/:courseId`                                                             | Learning course tree                   | Student with entitlement       | Integrated; backend authorizes protected data                                |
| `/learn/courses/:courseId/sections/:sectionId`                                         | Section                                | Student with entitlement       | Integrated                                                                   |
| `/learn/lessons/:lessonId`                                                             | Lesson workspace, notes and completion | Student with entitlement       | Integrated                                                                   |
| `/learn/exercises/:exerciseId`                                                         | Exercise and associated assets         | Student with entitlement       | Integrated                                                                   |
| `/learn/quizzes/:attemptId`                                                            | Quiz attempt                           | Student, attempt owner         | Integrated                                                                   |
| `/learn/quizzes/:attemptId/result`                                                     | Quiz result/review                     | Student, attempt owner         | Integrated; respects server review fields                                    |
| `/checkout/:orderContext`                                                              | Purchase/renewal quote and order       | Student                        | Integrated; server-calculated price                                          |
| `/orders/:id/pending`                                                                  | Pending order / transfer report        | Student, order owner           | Integrated; report remains PENDING                                           |
| `/orders/:id/result`                                                                   | Order result                           | Student, order owner           | Integrated                                                                   |
| `/admin`                                                                               | Admin dashboard                        | Admin                          | Integrated                                                                   |
| `/admin/courses`, `/admin/courses/:courseId`                                           | Course CMS                             | Admin                          | Integrated                                                                   |
| `/admin/courses/:courseId/sections/:sectionId`                                         | Section editor                         | Admin                          | Integrated                                                                   |
| `/admin/courses/:courseId/sections/:sectionId/lessons/:lessonId`                       | Lesson editor                          | Admin                          | Integrated                                                                   |
| `/admin/courses/:courseId/sections/:sectionId/lessons/:lessonId/exercises/:exerciseId` | Exercise/quiz editor                   | Admin                          | Integrated                                                                   |
| `/admin/media`                                                                         | Media library and associations         | Admin                          | API workflow integrated; real provider unavailable                           |
| `/admin/students`, `/admin/students/:userId`                                           | Student directory/detail/status        | Admin                          | Integrated                                                                   |
| `/admin/enrollments`, `/admin/enrollments/:enrollmentId`                               | Enrollment directory/detail/actions    | Admin                          | Integrated                                                                   |
| `/admin/orders`, `/admin/orders/:orderId`                                              | Order review/approval/cancellation     | Admin                          | Integrated                                                                   |
| `/admin/renewal-plans`                                                                 | Renewal plan management                | Admin                          | Integrated                                                                   |
| `/admin/coupons`                                                                       | Coupon management                      | Admin                          | Integrated                                                                   |
| `/admin/settings`                                                                      | Site/payment settings                  | Admin                          | Integrated                                                                   |
| `/admin/audit-logs`                                                                    | Audit history                          | Admin                          | Integrated                                                                   |
| `*`                                                                                    | Not found                              | Public                         | No data operation                                                            |

`/preview` and old chapter-position free access are not production routes. The UI passes actual course/lesson/exercise IDs to the API and does not grant access based on course name or order status.

Development-only routes (`/__dev/ui-kit`, `/__dev/lms-kit`, `/__dev/layouts/:layout`) and demo controls live in `frontend/src/app/App.tsx`; they are not imported by the production entry.
